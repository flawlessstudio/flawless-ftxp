# FTXP Canonical Execution Kernel

Execute FTXP v1.0 on the supplied target.

## Objective
Produce the most correct, materially complete, deduplicated, coherent, canonical, traceable, and useful faceted taxonomy possible within an explicit scope.

Do not maximize raw item count. Maximize correctness, conceptual distinctness, scope coverage, structural coherence, terminological canonicity, traceability, usability, simplicity, and only then additional breadth.

## Runtime input

```yaml
target: ""
objective: infer

scope:
  included: infer
  excluded: infer
  boundary_rule: infer
mode: auto
granularity: maximal-useful

  current: true
  historical: auto
  emerging: auto
cross_domain: auto
saturation_required: true
```

## Auto-mode selection

Use FT-L for narrow low-ambiguity targets.
Use FT-S by default.
Use FT-X only when breadth, polysemy, criticality, terminology instability, external evidence, historical coverage, cross-domain expansion, or ecosystem mapping materially justify it.

## Execution rules

1. Reconstruct intent before classification.
2. Normalize spelling, morphology, acronyms, aliases, and translations.
3. Separate materially distinct senses.
4. Lock scope before exhaustive expansion.
5. Build a provisional candidate universe using applicable discovery dimensions.
6. Resolve terminology before inclusion.
7. Deduplicate exact, lexical, referential, semantic, functional, and structural duplicates.
8. Build a primary hierarchy with coherent sibling classification criteria.
9. Activate only materially useful facets.
10. Add typed relationships when they improve structural understanding.
11. Expand recursively only to maximal useful granularity.
12. Run cross-cutting analysis for mixed abstraction levels, duplicate concepts, oversized buckets, misplaced nodes, and facets disguised as hierarchy.
13. Use evidence for material, current, formal, or externally verifiable claims.
14. Run an adversarial pass that actively searches for missing, redundant, misplaced, conflated, or unjustified concepts.
15. Classify new information as material or non-material novelty.
16. Continue until SAT-MAX is satisfied.
17. Run regression after material integrations and before freeze.

## Final self-audit

Before completion verify:

- Does the taxonomy solve the actual problem?
- Is anything duplicated?
- Are hierarchy and facets separated correctly?
- Are supposedly distinct concepts actually distinct?
- Are there material gaps?
- Is the structure simpler than an equally correct alternative?
- Is SAT-MAX justified?
- Is there any material reason not to freeze?

Correct solvable defects before emitting the final result.
