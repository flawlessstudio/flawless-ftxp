# Changelog

All notable changes to FTXP are documented here.

The project follows Semantic Versioning for protocol/repository baselines.

## [1.0.0] - 2026-09-06

### Added
- Initial frozen baseline of FTXP — Faceted Taxonomy Execution Protocol.
- Normative specification.
- Canonical Execution Kernel.
- FT-L, FT-S and FT-X execution profiles.
- Canonical Template Set: T1, T2 and T3.
- Canonical registries for concept types, facets, relationships, statuses, quality gates, material novelty and reopening triggers.
- SAT-MAX saturation protocol.
- Regression and validation model.
- GitHub-native repository governance and validation baseline.

### Changed
- The historical “Prompt de Taxonomía Facetada” is formally superseded as the primary abstraction by FTXP. Its executable role is preserved by the Canonical Execution Kernel.

### Security
- Repository automation is designed for least-privilege GitHub Actions permissions and deterministic dependencies.
